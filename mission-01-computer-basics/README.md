# Mission 1 - Know your computer

## 1. Task / objective
In this mission, I had to understand how a computer takes input, processes it, gives output and stores the result. I also had to identify hardware and software.

## 2. Work completed

### Task 1.1 - IPOS

I chose the example of typing and saving a document.

| Stage | What happens | Component |
|---|---|---|
| Input | I type text using the keyboard. | Keyboard |
| Processing | The computer processes the typed text and updates the document. | CPU and RAM |
| Output | I can see the text on the screen. | Monitor |
| Storage | I save the document so I can open it later. | SSD |

### Task 1.2 - Hardware and software

| Item | Type | Software type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | - | Used for typing |
| Mouse / trackpad | Hardware | - | Used to control the pointer |
| Monitor | Hardware | - | Shows what is happening |
| SSD | Hardware | - | Stores files |
| macOS | Software | Operating system | Manages the computer |
| Google Chrome | Software | Application | Used to browse websites |
| VS Code | Software | Application | Used to write code |
| Activity Monitor | Software | Utility | Shows running processes and resource usage |

### Task 1.3 - Computer systems around me

| System | Purpose | Input | Output |
|---|---|---|---|
| ATM | Used for banking | Card and PIN | Cash or account details |
| Traffic signal | Controls traffic | Timer / sensor | Traffic lights |
| Ticket machine | Gives travel tickets | Destination and payment | Ticket |

## 3. Commands / tools used
I used a text editor to prepare the tables. No Terminal commands were needed for this mission.

## 4. My understanding
I understood that a computer does four basic things: input, processing, output and storage. Hardware means the parts we can physically touch. Software is what we use to give instructions to the computer.
